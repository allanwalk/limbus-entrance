# 都市入境體驗 / City Entrance

免費、非官方、無劇透優先的 Project Moon 粉絲互動網站原型。

## 現有功能

- 三段可遊玩的原創互動事件與分支敘事
- 本機進度儲存、三種都市生存傾向結果
- 本機產生 PNG 分享卡
- 不需要帳號、後端或 API 金鑰

**注意：** 這是第一版可玩原型，並非先前規劃的完整 24 題十二罪人人格測驗，也沒有完整人生模擬或好友比較功能。選擇影響後續提示及結局傾向，尚未實作複雜事件樹。

## 執行與部署

直接開啟 `index.html`，或在 GitHub 儲存庫 Settings → Pages → Build and deployment 選擇 **Deploy from a branch**，分支 `main`，資料夾 `/ (root)`。部署後網址預計為 `https://allanwalk.github.io/limbus-entrance/`，但實際可用性需以 Pages 發布狀態為準。
